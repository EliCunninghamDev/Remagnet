Remagnet Proxy

Connects to qBittorrent on behalf of the Remagnet extension and Android app, applies the category and tags below to new magnets, and streams completed torrents as ZIP files. Torrent files are never stored on this server.

http://127.0.0.1:8080

Use this origin as the Remagnet Proxy URL in the extension or Android settings, with the same token. The proxy applies the magnet defaults above and only lists torrents it owns. Downloads only work for completed torrents.

Pair a device

Show a one-time code for the Remagnet Android app or the extension. Pairing sends only this proxy URL and token; your qBittorrent credentials stay on this server. The code rotates every minute, works once, and is revoked when you hide it.
