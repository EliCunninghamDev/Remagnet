Firefox · Chrome · Android · Self-hosted Docker proxy

Send magnets to your server. Stream finished torrents home.

Remagnet turns magnet links in Firefox, Chrome, and Android into one-click remote downloads on your qBittorrent server—then streams completed torrents straight to your device as ZIP files without exposing qBittorrent to the internet.

How it works

One tiny Rust proxy sits beside qBittorrent. Your devices never see qBittorrent's URL or credentials.

01 / CAPTURE

Native magnet intake

Firefox registers a magnet: handler, Chrome adds a magnet-only context menu item, and Android handles magnet: links and shared text system-wide.

02 / PROXY

Private qBittorrent adapter

Remagnet Proxy talks to qBittorrent inside your Docker network, tags Remagnet's own torrents, and scopes listing, removal, and downloads strictly to those tags.

03 / STREAM

Zero-disk ZIP downloads

Completed torrents stream file-by-file from qBittorrent's Web API straight into an uncompressed ZIP response—no mounted downloads volume and no temp files.

Quick start

Start the proxy, create your admin account in the browser, and connect your devices with direct sign-in or a 60-second QR code.

compose.yaml 
services:
  remagnet-proxy:
    image: ghcr.io/elicunninghamdev/remagnet-proxy:latest
    container_name: remagnet-proxy
    restart: unless-stopped
    env_file: .env
    environment:
      DATA_DIR: /data
      BIND_ADDR: 0.0.0.0:8080
    extra_hosts:
      - "host.docker.internal:host-gateway"
    ports:
      - "8080:8080"
    volumes:
      - remagnet-data:/data

volumes:
  remagnet-data:
.env (all fields optional — finish setup in the web UI) 
# Optional: require this code on first boot before creating the admin account.
SETUP_CODE=

# Where the proxy reaches qBittorrent's Web UI.
QBIT_BASE_URL=http://host.docker.internal:8080
QBIT_API_KEY=

# Category and tags owned by Remagnet.
REMAGNET_CATEGORY=remagnet
REMAGNET_TAGS=remagnet
Caddyfile (recommended HTTPS reverse proxy) 
remagnet.example.com {
  reverse_proxy remagnet-proxy:8080
}

Security & privacy by design

  • Admin vs. device isolation: Web UI admin sessions use Argon2id passwords, optional TOTP 2FA with recovery codes, and HttpOnly; SameSite=Strict cookies. Clients receive revocable per-device tokens (rmg_…) that cannot touch admin settings.
  • Two ways to connect: Sign in directly from the extension or Android app, or scan a single-use 60-second QR / pairing link from the proxy page without re-entering 2FA.
  • Zero telemetry: No hosted servers, analytics, or third-party requests. Read the full Privacy Policy or explore the OpenAPI 3.1 contract.
