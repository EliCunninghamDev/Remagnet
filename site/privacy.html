Privacy policy

Remagnet is a local-first browser extension, Android app, and self-hosted proxy. The project operates no accounts, no analytics, no telemetry, no advertising, and no servers of its own. Nothing you enter into Remagnet is sent to the project or to any third party.

What Remagnet stores

Remagnet only stores the settings you enter, on the device or server where you entered them.

Browser extension

  • The Remagnet Proxy URL is kept in the extension's local storage. The per-device proxy token is encrypted with AES-GCM before it is written to storage, using a non-extractable WebCrypto key kept in the extension's IndexedDB. The administrator password and any 2FA code are used only during sign-in and are not stored.
  • The extension stores no qBittorrent URL, username, API key, password, category, or tags. Those live only on the Remagnet Proxy.
  • Settings stay in that browser profile and are never synced to a Remagnet server.
  • On Chrome, a content script inspects only the URL of the currently hovered link so the context-menu item appears only on magnet: links. It does not read other page content or send anything off your device.

Android app

  • The per-device Remagnet Proxy token is encrypted with a key held by the Android Keystore; the proxy URL stays readable so Settings can render. The administrator password and any 2FA code are used only during sign-in and are not stored.
  • The app stores no qBittorrent URL, username, API key, password, category, or tags.
  • Pairing codes and scanned QR contents are used in memory only. A successful pairing saves only the proxy URL and newly minted device token.

Remagnet Proxy

  • config.json (mode 0600) on your server holds the qBittorrent Web UI URL, credentials, and Remagnet category/tags.
  • auth.json (mode 0600) holds the administrator username, Argon2id password hash, optional TOTP secret, SHA-256 hashes of unused recovery codes, and SHA-256 hashes plus metadata for connected devices. Raw passwords, 2FA codes, recovery codes, and device tokens are never written to disk.
  • Admin sessions, login rate limits, pairing codes (60s, single-use), and archive download tickets (60s, single-use, hash-bound) exist only in memory.
  • Completed torrent files are streamed directly from qBittorrent into a ZIP response and are never stored on disk by the proxy.

Network connections

The extension and Android app connect only to the Remagnet Proxy URL you configure. The proxy connects only to your qBittorrent instance. There are no update checks, crash reports, remote configuration fetches, or telemetry requests to the project.

Permissions

  • Extension storage: stores your proxy URL and encrypted device token.
  • Downloads: saves streamed ZIP archives of completed torrents.
  • Host access: optional host access is requested only for the proxy origin you configure. On Chrome, content-script access checks only hovered links for magnet: URLs.
  • Camera (Android): used only while scanning a pairing QR code.
  • Notifications (Extension & Android): reports torrent completion and archive download progress.

Deleting your data

  • Extension: click Disconnect in Settings (which also revokes the device token on your proxy) or remove the extension.
  • Android: tap Disconnect in Settings, clear app storage, or uninstall the app.
  • Proxy: delete config.json and auth.json (or the Docker data volume).
